# Build Agent Brief

Build a production-ready responsive football recruiting landing page for the Greater Naples Officials Association using:
1. `reference-images/00-full-page-mockup.png` as the visual authority.
2. The section crops to inspect spacing and local composition.
3. `docs/page-content.md` as the copy authority.
4. `tokens/design-tokens.css` as a starting design system.
5. `icons-svg/` for UI icons where appropriate.

Do **not** rasterize text into the page. Recreate all content as semantic HTML/CSS.

Use temporary image slots matching the production shot list if final photography is not yet supplied. The mockup crops may be used as design references, but should not be treated as final production photo assets.

Preserve these visual characteristics:
- Deep navy headers and bands
- Teal action color
- White/light-gray content areas
- Athletic, condensed-feeling large headlines
- Tight but readable body copy
- Rounded image/cards with subtle borders
- Large full-width football photography at key emotional moments
- Officials as primary visual subjects throughout

Priority conversion actions:
1. Become a Football Official
2. Experienced Official? Connect With GNOA
3. Start the Process
4. Football News & Recognition
5. Current Officials – Go to ArbiterSports
