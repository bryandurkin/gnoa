# Agent Build Brief — GNOA Soccer Recruiting Page

## Source of truth
1. `reference-images/00-full-page-mockup.png` = visual authority.
2. `docs/page-content.md` = copy/content authority.
3. Use the **simplified soccer mockup** and the simplified softball page as the shared design language.

## Design goal
Build a clean, easy-to-read soccer recruiting page in the established GNOA family. It should feel modern, athletic, credible, welcoming, and community-driven without becoming dense or templated.

## Core design rules
- More white space than the early GNOA sport-page concepts.
- Fewer bordered cards.
- Shorter visible text blocks.
- Large headings and strong hierarchy.
- Image-led sections.
- Large, simple circular icons.
- **No visible numbered process steps.**
- Each major section should have one obvious job and one clear CTA at most.

## Layout
### Header
Use the shared GNOA header. Keep navigation compact and the recruiting CTA obvious.

### Hero
Two-column desktop hero: dark navy copy treatment left, authentic soccer referee action image right. Referee should be the primary visual subject, not the players. Maintain generous spacing and strong contrast.

### Benefits
Four simple benefit items with circular icons. Avoid heavy card boxes.

### Training
Use a large assistant-referee / touchline image paired with a concise training message and scannable learning list. Keep the section open and editorial rather than box-heavy.

### Getting started
Five milestones horizontally on desktop using icons and spacing/arrows. **Do not add 1 / 2 / 3 / 4 / 5 numbers.** Stack cleanly on mobile.

### What makes a good referee / lower page
Continue the same simplified system below the current mockup: use open skill blocks, alternating image/text bands, and concise copy for Positioning, Judgment, Communication, Advantage, and Composure.

### Experienced officials
Use a mature crew/referee image with one short paragraph, compact experience list, and one CTA.

### Development
Present growth as a flexible path, not a rigid ranking ladder. Some officials simply want enjoyable local work; others want postseason/championship opportunities.

### Equipment + FAQs
Use a clean two-column desktop section. Equipment should be practical and reassuring. FAQ should be a semantic accordion on the live site.

### Final CTA
Keep a spacious, emotional closing band. The mockup uses a soccer ball field image; a real official-focused photo is preferable for production if available.

## Soccer-specific photography rules
- Referees should wear authentic soccer referee uniforms.
- Assistant-referee flag imagery is encouraged.
- Avoid baseball/softball caps or sport-inappropriate uniforms.
- Officials remain the main subject; players are context.
- Use real GNOA photography whenever possible.

## Responsive behavior
- Hero stacks text above image on mobile.
- Benefits become 2x2 then 1-column.
- Training image/text stack vertically.
- Getting-started flow becomes a clean vertical sequence without numbers.
- Skill blocks can become 2 columns then 1 column.

## Accessibility
- WCAG AA contrast.
- Visible keyboard focus.
- Semantic heading order.
- Useful alt text for photography.
- Decorative SVG icons `aria-hidden="true"`.
- Do not bake copy into image files.
