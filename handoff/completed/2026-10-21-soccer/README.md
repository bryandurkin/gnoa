# GNOA Soccer Website Handoff Pack

Built from the approved **simplified soccer recruiting-page mockup**.

## Contents
- `reference-images/` — full approved mockup plus section crops.
- `photo-crops/` — extracted photo/reference areas from the generated composite.
- `icons/` — editable navy and teal SVG icons.
- `design-tokens/` — CSS + JSON color/type/layout starting points.
- `docs/page-content.md` — soccer page copy and presentation direction.
- `docs/agent-build-brief.md` — implementation rules for the builder agent.
- `docs/production-image-shot-list.md` — recommended final photography.
- `docs/asset-manifest.csv` — asset map and production status.

## Important
The generated mockup is a single composite image. The included photo crops are **not original standalone source photographs**. They are useful for prototyping and visual matching, but should be replaced with GNOA-owned or properly licensed photography before launch.

## Visual authority
Use `reference-images/00-full-page-mockup.png` as the visual source of truth. This soccer page should follow the same simplified, low-density design language as the approved softball page.
