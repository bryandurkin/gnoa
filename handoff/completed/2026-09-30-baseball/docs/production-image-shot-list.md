# Production Photo Shot List

These are the preferred real-photo replacements for the mockup crops.

| Asset | Recommended crop | Subject / composition |
|---|---|---|
| Hero | 16:9 or 3:2, min 1800px wide | Plate umpire actively working, catcher/batter secondary, room for text left, Southwest Florida evening light |
| Mentoring | 3:2 | Veteran and newer umpire talking on-field; candid instruction, not classroom-only |
| Positioning | 4:3 | Base umpire set in proper position, active game context |
| Plate Work | 4:3 | Plate umpire in stance behind catcher |
| Base Mechanics | 4:3 | Umpire moving into angle or making safe/out call |
| Rules | 4:3 | Rulebook, notes, film session, or practical clinic |
| Judgment | 4:3 | Umpire confidently making a call |
| Communication | 4:3 | Two umpires conferring or calm umpire/coach interaction |
| Timing / First Game | 16:9 | Umpire from behind under lights, field action soft in background |
| Experienced Crew | 3:2 | 3–4 veteran baseball umpires together, professional/candid |
| New Umpire Training | 3:2 | Mechanics clinic or rules/film session |
| Local Baseball | 3:2 | GNOA umpire working local high-school or comparable game |
| Postseason | 3:2 | Crew walking onto field or pregame conference at higher-level game |
| Recognition / Championship | 3:2 | Crew at significant playoff/championship venue |
| Equipment | 4:3 | Clean flat lay: mask, chest protector, shin guards, indicator, brush, ball bags, shoes/cap |
| Final CTA | 16:9 | Umpire looking toward field at sunset/night, emotional but authentic |

## Usage guidance
Keep umpires as the dominant subject. Avoid generic baseball-stock imagery where only players are visible. When shooting local fields, palm trees, warm evening light, and real Southwest Florida venues can subtly establish place without becoming tourist imagery.
