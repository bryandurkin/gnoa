# GNOA Baseball Website Handoff Pack

This package is built from the approved baseball recruiting-page mockup.

## Contents
- `reference-images/` — full mockup plus section crops for layout matching.
- `photo-crops/` — extracted photo/reference areas from the composite mockup. These are **reference/prototype assets**, not original source photos.
- `icons/` — editable SVG icons in the GNOA navy/teal visual family.
- `design-tokens/` — approximate CSS/JSON design tokens.
- `docs/page-content.md` — clean approved page copy.
- `docs/agent-build-brief.md` — implementation instructions.
- `docs/production-image-shot-list.md` — recommended real-photo replacements.
- `docs/asset-manifest.csv` — quick map of assets and intended use.

## Important
The mockup was generated as one composite image, so there are no hidden standalone original photo files to download. The included photo crops are extracted from the mockup and are best used as build references or temporary prototype assets. Replace them with GNOA-owned/licensed photography for production when possible.
