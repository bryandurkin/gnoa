# GNOA Wrestling Website Handoff Pack

This package is built from the approved **Wrestling recruiting page** mockup using the cleaner GNOA sport-page design system.

## Contents
- `reference-images/` — full approved mockup plus section crops.
- `photo-crops/` — extracted visual references from the composite mockup. These are prototype/reference assets, not original source photography.
- `icons/` — editable SVG icons in navy and teal.
- `design-tokens/` — approximate CSS/JSON tokens.
- `docs/page-content.md` — exact approved wrestling-page copy.
- `docs/agent-build-brief.md` — implementation instructions.
- `docs/production-image-shot-list.md` — recommended production photography.
- `docs/asset-manifest.csv` — asset/use map.

## Source of truth
1. `reference-images/00-full-page-mockup.png` = visual authority.
2. `docs/page-content.md` = copy authority.
3. `design-tokens/` = implementation starting point.

## Important
The mockup is a single AI-composited image. Photo crops in this pack are visual references only. Replace them with GNOA-owned or properly licensed photography before launch whenever possible.
