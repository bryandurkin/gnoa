# GNOA Volleyball Website Handoff Pack

This package is built from the approved **cleaner volleyball recruiting-page mockup**.

## Contents
- `reference-images/` — approved full mockup plus section crops.
- `photo-crops/` — extracted visual references from the composite mockup; prototype/reference only.
- `icons/` — reusable editable SVG icons in navy and teal.
- `design-tokens/` — CSS/JSON implementation starting points.
- `docs/page-content.md` — full approved volleyball page copy.
- `docs/agent-build-brief.md` — instructions for the web builder.
- `docs/production-image-shot-list.md` — recommended production photography.
- `docs/asset-manifest.csv` — asset/use map.

## Source of truth
1. `reference-images/00-full-page-mockup.png` = visual direction and simplified layout style.
2. `docs/page-content.md` = complete copy authority.
3. `docs/agent-build-brief.md` = rules for extending that visual style through sections not shown in the mockup.

## Important
The mockup was generated as one composite image. The included photo crops are not hidden/original source photographs. Replace them with GNOA-owned or properly licensed imagery before production launch whenever possible.
