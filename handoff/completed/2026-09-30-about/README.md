# GNOA About Website Handoff Pack — Concise Version

This package is built from the approved **concise About GNOA page mockup**.

## Contents
- `reference-images/` — full approved mockup plus section crops for layout matching.
- `photo-crops/` — extracted photo/reference areas from the composite mockup. These are **reference/prototype assets**, not original source photographs.
- `icons/` — reusable editable SVG icons in navy and teal variants.
- `design-tokens/` — approximate CSS/JSON tokens for the approved GNOA design family.
- `docs/page-content.md` — approved concise About page copy.
- `docs/agent-build-brief.md` — implementation instructions for the build agent.
- `docs/production-image-shot-list.md` — recommended production photo replacements.
- `docs/asset-manifest.csv` — quick asset/use map.

## Source of truth
1. `reference-images/00-full-page-mockup.png` = visual authority.
2. `docs/page-content.md` = copy authority.
3. `design-tokens/` = implementation starting point.

## Important image note
The approved mockup is a single generated composite image. The files in `photo-crops/` are extracted visual references only. They are useful for layout/prototyping but should be replaced with GNOA-owned or properly licensed photography for production whenever possible.
